# سناریوهای E2E — SaaS چندمستأجری

چک‌لیست دستی برای staging/پروداکشن. هر ردیف: پیش‌شرط → اقدام → انتظار.

## A) هویت و tenant

| # | سناریو | انتظار |
|---|--------|--------|
| A1 | OTP با شماره عضو یک سازمان | ورود بدون picker |
| A2 | OTP با شماره عضو دو سازمان | نمایش انتخاب سازمان؛ انتخاب درست scope می‌کند |
| A3 | ورود از ساب‌دامین الماس در حالی که عضو آن tenant هستید | همان tenant انتخاب می‌شود |
| A4 | ورود از ساب‌دامین سازمانی که عضو نیستید | hint ذخیره می‌شود ولی دسترسی به داده آن tenant ندارید |
| A5 | JWT جعلی / بدون session روی جدول customers | RLS رد می‌کند (خطا / خالی) |

## B) نشت cross-tenant

| # | سناریو | انتظار |
|---|--------|--------|
| B1 | دو tenant با مشتری‌های جدا؛ کاربر A فقط A را می‌بیند | هیچ ردیف B در UI/Network |
| B2 | فراخوانی RPC/select با `tenant_id` سازمان B توسط کاربر A | رد یا خالی |
| B3 | بکاپ export از A شامل داده B نیست | تأیید در فایل خروجی |

## C) پلن و entitlement

| # | سناریو | انتظار |
|---|--------|--------|
| C1 | Trial فعال | چت/ماتریس/عودت/ارسالی باز؛ ساب‌دامین بسته |
| C2 | طلایی فعال | چهار قابلیت الماس مخفی/قفل؛ CRM پایه باز |
| C3 | الماسی فعال | همه الماس + ساب‌دامین |
| C4 | سوپرادمین تنزل الماس→طلایی | UI قفل؛ resolve ساب‌دامین دیگر tenant برنمی‌گرداند |

## D) انقضا و grace

| # | سناریو | انتظار |
|---|--------|--------|
| D1 | Trial با `trial_ends_at` گذشته (یا بعد از cron) | readonly + paywall + قطع import/export |
| D2 | اشتراک پولی منقضی داخل grace | بنر grace + قابل نوشتن + بدون paywall اجباری |
| D3 | بعد از اتمام grace (cron) | readonly + paywall |
| D4 | سازمان suspended / archived | دسترسی محدود؛ ساب‌دامین پاک |

## E) پرداخت

| # | سناریو | انتظار |
|---|--------|--------|
| E1 | checkout طلایی sandbox موفق | `billing_payments=paid`، subscription active، صفحه نتیجه ok |
| E2 | کاربر Cancel در زرین‌پال | status cancelled؛ پلن عوض نشده |
| E3 | verify ناموفق | failed؛ پلن عوض نشده |
| E4 | دوبار باز کردن callback موفق | idempotent؛ یک فعال‌سازی |
| E5 | پرداخت دستی از `/platform` | active + ردیف audit |

## F) Onboarding

| # | سناریو | انتظار |
|---|--------|--------|
| F1 | ثبت‌نام سازمان جدید از `/signup` | tenant + owner + trial |
| F2 | محدودیت ساخت چند tenant در یک روز با یک شماره | 429 / پیام فارسی |
| F3 | دعوت عضو با موبایل | عضویت جدید؛ audit `tenant.invite_member` |

## G) UX paywall

| # | سناریو | انتظار |
|---|--------|--------|
| G1 | بعد از trial_ended مودال با عنوان مناسب | متن فارسی صحیح |
| G2 | «ادامه فقط‌خواندنی» | مودال تا انتهای session برای همان reason برنمی‌گردد |
| G3 | بنر grace دکمه تمدید | باز شدن وضعیت اشتراک |
| G4 | تلاش import در readonly | toast + بدون اجرا |

## H) ساب‌دامین و پلتفرم

| # | سناریو | انتظار |
